# سامانه مدیریت پارکینگ | Parking Management System

## معرفی پروژه

این پروژه یک سامانه دسکتاپ برای مدیریت پارکینگ است که با زبان Java و فریم‌ورک JavaFX طراحی و پیاده‌سازی شده است. هدف اصلی این سامانه، مدیریت ورود و خروج وسایل نقلیه، محاسبه هزینه توقف، صدور رسید دیجیتال، مدیریت کاربران، مدیریت شیفت اپراتورها، مدیریت تعرفه‌ها، مشاهده وضعیت جایگاه‌ها و تولید گزارش‌های مدیریتی است.

این برنامه برای استفاده در محیط‌های پارکینگ طراحی شده و امکان مدیریت خودرو و موتورسیکلت را فراهم می‌کند.

## امکانات اصلی پروژه

### ۱. ورود کاربران به سیستم

کاربران می‌توانند با نام کاربری و رمز عبور وارد سیستم شوند. رمز عبور کاربران به صورت هش‌شده ذخیره می‌شود و رمز خام در دیتابیس نگهداری نمی‌شود.

### ۲. مدیریت نقش‌ها و سطح دسترسی

در این سامانه سه نقش اصلی وجود دارد:

| نقش | توضیح |
|---|---|
| OWNER | مالک سیستم با دسترسی کامل |
| ADMIN | مدیر سیستم با دسترسی مدیریتی |
| OPERATOR | اپراتور با دسترسی محدود برای ثبت ورود و خروج |

بر اساس نقش کاربر، بخش‌های مختلف برنامه فعال یا محدود می‌شوند.

### ۳. ثبت ورود وسیله نقلیه

در بخش ثبت ورود، نوع وسیله نقلیه و شماره پلاک وارد می‌شود. سیستم ابتدا بررسی می‌کند که پلاک قبلاً در پارکینگ ثبت نشده باشد و سپس یک جایگاه خالی به وسیله اختصاص می‌دهد.

### ۴. ثبت خروج وسیله نقلیه

در زمان خروج، سیستم با استفاده از شماره پلاک، اطلاعات ورود وسیله را پیدا می‌کند، مدت توقف را محاسبه می‌کند، هزینه نهایی را بر اساس تعرفه محاسبه کرده و رسید دیجیتال تولید می‌کند.

### ۵. صدور رسید دیجیتال

پس از ثبت خروج، رسید شامل اطلاعات زیر تولید می‌شود:

- شماره رسید
- شماره پلاک
- نوع وسیله
- زمان ورود
- زمان خروج
- مدت توقف
- هزینه نهایی

همچنین امکان چاپ رسید از داخل برنامه وجود دارد.

### ۶. مدیریت تعرفه‌ها

مالک یا ادمین می‌تواند تعرفه خودرو و موتورسیکلت را تغییر دهد. تعرفه‌ها شامل موارد زیر هستند:

- هزینه ساعت اول
- هزینه ساعت‌های بعدی
- سقف هزینه شبانه‌روزی

### ۷. مدیریت جایگاه‌های پارکینگ

سیستم وضعیت جایگاه‌های پارکینگ را نمایش می‌دهد. هر جایگاه می‌تواند خالی یا اشغال باشد. هنگام ورود وسیله، یک جایگاه خالی اختصاص داده می‌شود و هنگام خروج، همان جایگاه آزاد می‌شود.

### ۸. مدیریت کاربران

در این بخش امکان مشاهده، افزودن، ویرایش و بایگانی کاربران وجود دارد. کاربران شامل مالک، ادمین و اپراتور هستند.

### ۹. مدیریت شیفت‌های کاری

اپراتورها می‌توانند شیفت کاری خود را شروع یا پایان دهند. مالک و ادمین نیز می‌توانند شیفت‌های اپراتورها را مشاهده کنند.

### ۱۰. گزارش‌گیری

سامانه امکان تولید گزارش‌های مختلف را دارد:

- گزارش روزانه
- گزارش هفتگی
- گزارش ماهانه
- گزارش بازه دلخواه
- گزارش عملکرد اپراتورها

در گزارش‌ها اطلاعاتی مانند تعداد ورود، تعداد خروج، درآمد و میانگین اشغال پارکینگ نمایش داده می‌شود.

### ۱۱. پشتیبانی از تاریخ شمسی

در بخش‌هایی مانند گزارش‌ها و مدیریت شیفت‌ها از تاریخ شمسی استفاده شده است تا برنامه برای کاربران فارسی‌زبان مناسب‌تر باشد.

## توضیح پوشه‌ها

### controller

این پوشه شامل کنترلرهای رابط کاربری است. کنترلرها مسئول ساخت صفحات، دریافت ورودی از کاربر و ارتباط با سرویس‌ها هستند.

نمونه کنترلرها:

- LoginController
- MainController
- ProfileController
- ReportController
- ShiftManagementController
- UserManagementController

### model

این پوشه شامل مدل‌های داده‌ای برنامه است. مدل‌ها ساختار اطلاعات را مشخص می‌کنند.

نمونه مدل‌ها:

- User
- Vehicle
- VehicleType
- ParkingSession
- ParkingTicket
- Tariff
- Shift
- DailyStat
- Role

### service

این پوشه شامل منطق اصلی برنامه است. سرویس‌ها عملیات پشت‌صحنه را انجام می‌دهند.

نمونه سرویس‌ها:

- AuthService
- ParkingService
- ReportService
- ShiftService
- OperatorPerformance

### database

این پوشه شامل کلاس مدیریت پایگاه داده است. کلاس DatabaseManager مسئول اتصال به SQLite، ساخت جدول‌ها و اجرای عملیات دیتابیس است.

### util

این پوشه شامل کلاس‌های کمکی است.

نمونه کلاس‌ها:

- PasswordHasher
- PasswordValidator
- PersianDateUtil
- PersianDatePickerUtil

### resources

این پوشه شامل فایل‌های ظاهری و منابع برنامه مانند CSS و تصاویر است.

## پایگاه داده

پایگاه داده پروژه از نوع SQLite است و در فایل زیر قرار دارد:

```text
parking.db
```

در زمان اجرای برنامه، در صورت نیاز جدول‌های اصلی توسط DatabaseManager ایجاد می‌شوند.

---

## جدول‌های اصلی دیتابیس

| جدول | کاربرد |
|---|---|
| users | ذخیره اطلاعات کاربران |
| tariffs | ذخیره تعرفه خودرو و موتورسیکلت |
| active_sessions | ذخیره وسایل نقلیه‌ای که در حال حاضر داخل پارکینگ هستند |
| parking_history | ذخیره تاریخچه خروج‌ها و رسیدها |
| parking_spots | ذخیره جایگاه‌های پارکینگ |
| shifts | ذخیره شیفت‌های اپراتورها |
| daily_stats | ذخیره یا نمایش آمار روزانه |

## توضیح معماری پروژه

این پروژه به صورت لایه‌ای طراحی شده است:

```text
Controller  →  Service  →  DatabaseManager  →  SQLite
```

### Controller

کنترلرها با رابط کاربری و کاربر در ارتباط هستند.

### Service

سرویس‌ها منطق اصلی برنامه را انجام می‌دهند.

### DatabaseManager

این کلاس عملیات دیتابیس را انجام می‌دهد.

### SQLite

اطلاعات برنامه در دیتابیس SQLite ذخیره می‌شود.

## نمونه جریان ثبت ورود

1. کاربر نوع وسیله و پلاک را وارد می‌کند.
2. MainController اطلاعات را دریافت می‌کند.
3. ParkingService ظرفیت و تکراری نبودن پلاک را بررسی می‌کند.
4. یک جایگاه خالی انتخاب می‌شود.
5. اطلاعات ورود در active_sessions ذخیره می‌شود.
6. وضعیت جایگاه در parking_spots به اشغال تغییر می‌کند.

---

## نمونه جریان ثبت خروج

1. کاربر پلاک وسیله را وارد می‌کند.
2. ParkingService وسیله را در active_sessions پیدا می‌کند.
3. مدت توقف محاسبه می‌شود.
4. تعرفه مناسب از جدول tariffs دریافت می‌شود.
5. هزینه نهایی محاسبه می‌شود.
6. وسیله از active_sessions حذف می‌شود.
7. جایگاه مربوطه آزاد می‌شود.
8. رسید دیجیتال ساخته می‌شود.
9. اطلاعات خروج در parking_history ذخیره می‌شود.

## امنیت رمز عبور

در این پروژه رمزهای عبور به صورت مستقیم ذخیره نمی‌شوند. ابتدا رمز عبور با استفاده از الگوریتم SHA-256 هش می‌شود و سپس مقدار هش‌شده در دیتابیس ذخیره می‌گردد.

کلاس‌های مرتبط:

- PasswordHasher
- PasswordValidator
- AuthService
